# Glossaire technique

| Terme | Definition |
|-------|------------|
| **AD** | Active Directory — service d'annuaire Microsoft pour l'authentification et la gestion des utilisateurs |
| **AES-256** | Advanced Encryption Standard, chiffrement symetrique 256 bits |
| **AF31** | Assured Forwarding 31 — classe DSCP pour trafic serveur prioritaire |
| **BE** | Best Effort — classe DSCP par defaut, sans garantie de priorite |
| **CAPEX** | Capital Expenditure — investissement initial (achat materiel, licences) |
| **Cross-dock** | Site de transit saisonnier, active pendant les pics d'activite |
| **DC** | Domain Controller — serveur Active Directory |
| **DPD** | Dead Peer Detection — mecanisme de detection de perte de tunnel VPN |
| **DSCP** | Differentiated Services Code Point — marquage de paquets pour la QoS |
| **EF** | Expedited Forwarding — classe DSCP haute priorite pour la VoIP |
| **EOL** | End of Life — fin de vie, plus de support ni de mises a jour |
| **ESP** | Encapsulating Security Payload — protocole IPsec pour le chiffrement |
| **FortiGate** | Pare-feu Fortinet, utilise pour la securite reseau |
| **FortiGuard** | Service de securite Fortinet (antivirus, IPS, web filter) |
| **HA** | High Availability — haute disponibilite, capacite a continuer de fonctionner malgre une panne |
| **IKEv2** | Internet Key Exchange version 2 — protocole de negociation VPN |
| **IPBX** | IP Private Branch Exchange — central telephonique IP |
| **IPsec** | Internet Protocol Security — protocole de tunnel VPN chiffre |
| **iSCSI** | Internet Small Computer Systems Interface — protocole de stockage via le reseau |
| **LAN** | Local Area Network — reseau local |
| **MFA** | Multi-Factor Authentication — authentification a facteurs multiples |
| **OPEX** | Operational Expenditure — couts recurrents (abonnements, maintenance) |
| **pfSense** | Firewall/routeur open-source base sur FreeBSD |
| **PoE** | Power over Ethernet — alimentation electrique via cable reseau |
| **PRA** | Plan de Reprise d'Activite — procedures pour reprendre apres un sinistre |
| **PSK** | Pre-Shared Key — cle secrete partagee pour l'authentification VPN |
| **QoS** | Quality of Service — mecanisme de priorisation du trafic reseau |
| **RAID5** | Redundant Array of Independent Disks level 5 — stockage avec tolerance de panne (1 disque) |
| **RPO** | Recovery Point Objective — perte de donnees maximale acceptable |
| **RTO** | Recovery Time Objective — duree maximale d'indisponibilite acceptable |
| **RTP** | Real-time Transport Protocol — protocole de transport pour la voix/video |
| **SAN** | Storage Area Network — reseau de stockage dedie |
| **SIP** | Session Initiation Protocol — protocole de signalisation pour la VoIP |
| **SPOF** | Single Point of Failure — composant dont la panne arrete tout le systeme |
| **TCO** | Total Cost of Ownership — cout total de possession sur une periode |
| **VLAN** | Virtual LAN — reseau virtuel permettant la segmentation logique |
| **VoIP** | Voice over IP — telephonie sur reseau IP |
| **VPN** | Virtual Private Network — tunnel chiffre entre deux sites |
| **WAN** | Wide Area Network — reseau etendu (inter-sites) |
| **WMS** | Warehouse Management System — systeme de gestion d'entrepot (coeur de metier NordTransit) |
